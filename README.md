### Featured Projects

- [TrueThread](https://github.com/sk200005/TrueThread) — A production-oriented AI research system built with React, Node.js, FastAPI, PostgreSQL, Redis and LangGraph. Uses microservices, BullMQ job queues, parallel agent workflows, RAG, pgvector and real-time SSE streaming to process and evaluate information from Reddit, YouTube and Wikipedia.

- [Insight News](https://insight-news-eight.vercel.app/) — A full-stack news intelligence platform with a 4-stage Ingest → Scrape → Summarize → Bias pipeline. It aggregates RSS articles, performs automated fact-checking, computes weighted bias scores using LLM and ML signals, and uses AWS EC2 and Hugging Face Spaces for deployment.

- [GradeX](https://github.com/sk200005) — A full-stack academic management system using Node.js, Express.js and MongoDB, with separate OLTP/OLAP workloads and a Star Schema data warehouse. Includes data-mining-based at-risk student identification, role-based authentication and bulk CSV processing.
